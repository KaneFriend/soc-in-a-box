# soc-in-a-box.
## This is a production-grade SIEM deployment on Free hardware.
### What this is:

This is a complete, automated deployment of a production-grade SOC on free hardware, combining the use of a Raspberry Pi (4gb version) & a spare laptop I had floating around. I've designed this SOC-in-a-box with [Wazuh](https://wazuh.com/), mirroring the experience I have with Splunk Cloud. 

---

### Architecture:
**Laptop (windows 10, x86)** Wazuh manager, Indexer & Dashboard.
**Raspberry Pi (ARM)** Wazuh Agent & Telemetry generator.
